# Real datasets (from Kaggle)

Included here only for this college lab project (Data Mining and Data Warehousing Lab, JIIT) so the pipeline runs without extra downloads.
All rights remain with the original authors; please follow the terms on the Kaggle pages.

| File | Source |
|---|---|
| `university_canteen_waste.csv` | Food Waste Dataset from a University Canteen: https://www.kaggle.com/datasets/rahuljangir78/food-waste-dataset-from-a-university-canteen |
| `messy_zip/train.csv`, `messy_zip/test.csv` | Messy Food Waste Prediction Dataset: https://www.kaggle.com/competitions/messy-food-waste-prediction-dataset/data |

Note: `test.csv` has the same features as `train.csv` (all IDs overlap), so only `train.csv` is used for modelling (5-fold CV).
